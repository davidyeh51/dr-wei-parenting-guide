  2. **螢幕界線與共同注意**：恪守「視頻缺陷效應」，保護「共同注意（Joint Attention）」，餐桌睡前無手機。
  3. **因果地圖構建**：扔東西是物理實驗，保護小小科學家因果探索（Causal Map）。
  4. **數理幾何直覺**：模糊數感啟蒙、形狀特徵聯想、睡前聊生活數學。
  5. **空間頂葉活化**：高頻使用「上下裡外前後」方位詞，多玩積木與磁力片。
  6. **前額葉不打擾原則**：沉浸玩耍時大人不插話不送水果，玩具角動靜分區＋秘密小帳篷。
